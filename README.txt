# 値上げ計算アプリ（Android向け）

## できること
- 元の数値とアップ率から値上げ後の金額を計算
- 四捨五入／切り上げ／切り捨て
- 小数点以下0〜4桁の指定
- リセットボタン
- インストール後のオフライン利用
- ホーム画面からアプリのように起動

## まず試す
`index.html` をChromeで開くと計算機能を試せます。オフラインキャッシュとホーム画面へのインストール機能を使うには、HTTPS対応のWebサイトにこのフォルダー内のファイルを一式アップロードしてください。サービスワーカーは通常、HTTPSまたはlocalhostでのみ動作します。

## Androidスマホに追加
1. HTTPSで公開したアプリのURLをAndroidのChromeで開きます。
2. メニュー（︙）を開き、「ホーム画面に追加」または「アプリをインストール」を選びます。
3. 追加後はホーム画面のアイコンから起動できます。
4. 最初に一度オンラインで開けば、必要なファイルが保存され、その後はオフラインでも使えるようになります。

※ 端数処理は指定した小数点以下の桁数に合わせて行います。例えば0桁なら整数、2桁なら小数第2位までの結果になります。
